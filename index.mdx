Welcome to the AmazeCC developer handbook. This is the aggregated home of everything you need to understand, run, extend, and ship AmazeCC — the app that replaces VIT's official portal for 20,000+ students.

New here? Start with the quickstart, then walk the web foundation like you'd learn the product from scratch.

<Tip>
  The full handbook syncs automatically from the [AmazeCC repository](https://github.com/AmazeContinuityProjects/AmazeCC) — edit the source docs there, not here. This site is rebuilt by the [aggregate workflow](https://github.com/AmazeContinuityProjects/docs/actions).
</Tip>
