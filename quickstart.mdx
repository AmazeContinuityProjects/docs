This is the fastest path to a running AmazeCC dev environment. It ends with you looking at your own local copy of the app, pre-populated with demo data.

<Note>
  AmazeCC is a static export of a Next.js 16 app — no database, no backend of its own, no VTOP account required for development. The backend lives in [AmazeContinuityProjects/AmazeCC-API](https://github.com/AmazeContinuityProjects/AmazeCC-API).
</Note>

## Prerequisites

Before you begin, you need:

- **Node.js 22 LTS** (v22.x) — check with `node --version`
- **pnpm** — via Corepack: `corepack enable && corepack prepare pnpm@latest --activate`
- **git**
- Any modern browser (Chrome or Edge recommended — service worker tooling first-class)

<Note>
  Never `npm install` here. The repo enforces pnpm in `.npmrc` and the lockfile is strict.
</Note>

## Get started

<Steps>
  <Step title="Clone and install">
    ```bash
    git clone https://github.com/AmazeContinuityProjects/AmazeCC.git
    cd AmazeCC
    pnpm install
    ```
    About 1–4 minutes depending on network.
  </Step>
  <Step title="Run the dev server">
    ```bash
    pnpm dev
    ```
    Opens at **https://localhost:3001** (self-signed cert — click through the warning), or use `pnpm dev:http` for plain HTTP.
  </Step>
  <Step title="Click “Try the demo”">
    On the landing page, choose **Try the demo** — the entire app fills with a fictional student's data: attendance, marks, grades, FFCS planner, everything. No network calls, nothing leaves your browser.
  </Step>
  <Step title="Make your first change">
    Edit any text in `src/components/custom/app/GuestExperience.tsx` and save — the dev server hot-reloads instantly. See [Getting Started](/amazecc/01-getting-started/index) for the real handbook.
  </Step>
</Steps>

## Run the tests

```bash
pnpm run test          # all 200+ suites
pnpm run test -- ffcs  # just the FFCS suites
```
